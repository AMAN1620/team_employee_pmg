SBI Framework Primer

High-impact feedback minimizes defensiveness and focuses on observable behavioral outcomes.

Situation (When & Where)

Anchor feedback in a specific time and anchor event so memory is fresh.

Behavior (What you observed)

Describe observable actions, not character assumptions or personality traits.

Impact (The result)

Explain the measurable effect on the squad, timeline, or customer trust.
